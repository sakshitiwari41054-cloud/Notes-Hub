# NotesHub

A static website with notes, questions, a quiz and a question-and-answer helper for Computer Fundamentals, Data Structures, DBMS, Computer Graphics, OOPs, Java, Python, C and C++. No backend or database needed.

Subject keys used in the data files: `fundamentals`, `ds`, `dbms`, `graphics`, `oops`, `java`, `python`, `c`, `cpp`.

## What is inside

| Section | What it does |
|---|---|
| 📚 Library | All notes and questions with search, subject, type and level filters |
| 🎯 Quiz | Multiple choice quiz (up to 10 questions), instant feedback, score, review of mistakes, best score per subject |
| 🤖 Ask NotesBot | The student types a question and gets the answer from the notes, with related topics. Hinglish questions work too |
| 🔥 Study streak | Counts the days in a row a student studies (opens a note, answers a quiz question or asks NotesBot) |

Streak, quiz best scores and the other progress are saved in each student's own browser, so every student has their own.

## Run it in VS Code

1. Install the **Live Server** extension in VS Code.
2. Use `File > Open Folder` and open the `notes-hub` folder.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also simply double-click `index.html` to open it in a browser.

## Add a new note, question or quiz MCQ

1. Open `admin.html` with Live Server (for example `http://127.0.0.1:5500/admin.html`).
2. Choose the **Type**: Note, Question or Quiz question (MCQ), and fill in the form.
3. Click **Generate code**, then **Copy code**.
4. Paste it right below the first line of the file shown on the page:
   - notes and questions go in `notes-data.js`, below `window.NOTES = [`
   - quiz MCQs go in `quiz-data.js`, below `window.QUIZ = [`
5. Save the file. The page refreshes automatically.

NotesBot reads `notes-data.js`, so every new note and question is searchable by it straight away.

## Quiz question format (if you write it by hand)

```js
{ s: "java", q: "Which keyword inherits a class?", o: ["implements", "extends", "inherits", "super"], a: 1, e: "extends is used for class inheritance." },
```

`s` is the subject key, `o` has exactly 4 options, `a` is the position of the correct option (0 is the first) and `e` is the explanation. The options are shuffled every time.

## About NotesBot

NotesBot is not an internet AI like ChatGPT. It searches the notes and questions on this site and shows the best matching answer. This means it works offline and is free, but it can only answer topics that are in your notes. If you add more notes, it gets smarter.

A real AI model needs a server or an API key, which a static site cannot keep secret. It can be added later with a small backend if you want it.

## Attach a PDF

1. Put the PDF inside the subject folder, for example `files/java/` or `files/dbms/`.
2. In `admin.html`, enter `files/java/name.pdf` in the **PDF path** field.
3. An **Open PDF** button will appear inside the note.

## Content format

| Write | Result |
|---|---|
| `## Heading` | heading |
| `**bold**` | bold text |
| `@@code@@` | inline code |
| `- item` | bullet list |
| `~~~java` ... `~~~` | code block (with a copy button) |

Code generated by `admin.html` already handles special characters. If you write directly in `notes-data.js`, the content sits inside a backtick (`` ` ``) string: do not use backticks in it (use `@@ @@` or `~~~` for code), and write `\n` in C code as `\\n`.

## Put it online for students

This is a static site, so any free host works: GitHub Pages, Netlify or Cloudflare Pages. Upload the whole `notes-hub` folder and share the link. Every note has its own link (for example `index.html#java-what-is-java`).

## One important note

`admin.html` only generates code. It cannot save files by itself. If you publish the site online, you can delete `admin.html` before uploading.
